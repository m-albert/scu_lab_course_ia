# Installing Fiji

Fiji can be downloaded as a self-contained package [here](http://fiji.sc).

It's installed by simply extracting the compressed zip archive and placing the resulting folder in a convenient.

```{admonition} Fiji and ImageJ
Fiji is a distribution of ImageJ, which comes bundled with a lot of useful plugins for scientific image analysis. Fiji stands for "Fiji Is Just ImageJ".
```

To confirm that Fiji is working, launch the application by opening the `Fiji.app` folder and double-clicking on the Fiji executable.

```{admonition} Multiple Fiji installations
Several instances of Fiji can coexist and run independently on a computer. This can be useful e.g. when different versions of Fiji plugins are needed for different applications.
```
