Exercise: Python Basics#

Duration ~45 min  ·  Session Day 0, at home

Practice for 00_python_basics. The tasks follow the same order, so if one has you stuck, the answer is in the matching section of the walkthrough.

No course data needed: everything makes its own numbers up.

Each task has hints that go from a nudge to nearly the answer. Take the first one first.

Task 2: lists#

Here are the areas of eight objects.

Print the number of objects, the smallest and largest area, and the average. Then print the first three areas and the last one.

Hint 1

len(), min(), max() and sum() all take a list.

Hint 2

The average is sum(areas) / len(areas). The first three are areas[:3] and the last is areas[-1].

areas = [236, 512, 480, 1305, 390, 875, 61, 505]

print(f"{...} objects")
print(f"smallest : {...}")
print(f"largest  : {...}")
print(f"average  : {...:.1f}")

print(f"last        : {...}")

Task 3: loops and decisions#

Go through areas and print one line per object saying whether it is too small (under 100), too big (over 1000) or plausible.

Then print how many were plausible.

Hint 1

A for loop with an if / elif / else inside it. Remember the indentation.

Hint 2

Keep a counter: set plausible = 0 before the loop and plausible += 1 inside the branch that matches.

# --- your turn ---
plausible = 0

for area in areas:
    if ...:
        verdict = "too small"
    elif ...:
        verdict = "too big"
    else:
        verdict = "plausible"
        ...
    print(f"{area:5d} px  ->  {verdict}")

print(f"{plausible} of {len(areas)} are plausible")

Make a mask of the pixels above 50. Print how many there are, what fraction of the image that is, and the average value of just those pixels.

Then make a copy of the image with everything below 50 set to zero.

Hint 2

image[mask] selects just those values. For the last part use .copy() first, then assign with the opposite mask: copy[~mask] = 0 (~ means “not”).

If you finish early#

Two things worth trying, because they are the mistakes that cost people time:

  1. Run a = np.array([1, 2, 3]), then b = a, then b[0] = 99. Print a. Were you expecting that? Now try it with b = a.copy().

  2. In a fresh cell write x = 5. Run it. Now change it to x = 10 but do not run it, and in the next cell print x. What do you get, and why?

If both of those surprised you, reread the warning in section 12 and the tip in section 1: between them they explain most of the confusing behaviour you will hit in a notebook.
